使用提醒（藍芽模式）

  1. 小車燒錄藍芽版程式（顯示 W2 → BLE）。右上角選「🔵 藍芽」。
  2. 開啟悟空板電源，等 micro:bit 顯示 BLE 後按「連接 micro:bit」。
  3. 選擇視窗中每台車都叫 BBC micro:bit [五個字母]，多台車時請先記下自己那台的名字。
  4. 藍牙意外中斷時，網頁會自動重新連線（最多 5 次），不需要重新選擇裝置。

判斷斷線原因：斷線後 micro:bit 若重新捲動顯示 W2 → BLE，代表它重開機了（多半是電池電量不足或伺服馬達卡住）；若顯示哭臉，才是單純的藍牙斷線。

請使用 Chrome 或 Edge（Windows / macOS / Android）。網頁必須以 https:// 或 localhost 開啟才能使用藍牙與鏡頭。

使用提醒（無線電模式）

  1. 準備兩片 micro:bit：小車燒錄「無線電版小車程式」（顯示 R1），橋接板燒錄「橋接板程式」並用 USB 線插在電腦上。右上角選「📻 無線電」。
  2. 小車程式的 RADIO_GROUP 要和 ⚙️ 設定的「無線電群組」相同（預設都是 1）。多台車時每組用不同數字。
  3. 按「連接橋接板」，在視窗中選擇 mbed Serial Port / BBC micro:bit CMSIS-DAP（COM 幾號都可以）。
  4. 狀態列出現「小車在線 ✓」就可以開始操作。USB 被拔掉再插回時會自動重新連線。

判斷斷線原因：小車開機會顯示 R1 → 群組數字；之後若又看到 R1，代表它重開機了（多半是電池電量不足或伺服馬達卡住）。若顯示哭臉，代表 3 秒沒收到無線電訊號（網頁關閉、橋接板拔掉或距離太遠）。

請使用電腦版 Chrome 或 Edge。網頁必須以 https:// 或 localhost 開啟才能使用序列埠、麥克風與鏡頭。一次只能有一個程式開啟序列埠：請先關閉 MakeCode 的「顯示主控台」。
